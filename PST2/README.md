# FIT1056 - PST2: Music School Management System (MSMS)

## Overview
This stage replaces temporary memory storage with full JSON persistence (`msms.json`).

## Requirements Completed
- **File Persistence:** Read/Write whole state via `json.load()` and `json.dump()`.
- **CRUD Integration:** Update/Remove routines for both Teachers and Students.
- **Receptionist Utilities:** Automatic attendance check-in logger and printable `.txt` badge cards.

## Run Instructions
```bash
python3 pst2_main.py
